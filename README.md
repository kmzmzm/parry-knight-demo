# 받아치는 기사 (Parry Knight) — 데모

보스의 공격을 타이밍 맞춰 받아쳐서 쓰러뜨리는 보스 러시 액션 게임의 플레이테스트용 데모입니다.

## 받는 법

1. 오른쪽 **Releases**(또는 [여기](../../releases/latest))에서 `ParryKnight_Demo_v…zip`을 받습니다. `Source code`는 받지 않아도 됩니다.
2. zip 파일에 마우스 오른쪽 버튼 → **모두 압축 풀기**
3. 풀린 폴더에서 **ParryKnight Demo** 실행
4. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (개인이 만든 게임이라 서명이 없어서 뜹니다)

Windows 10 / 11 (64비트) 전용입니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | WASD |
| 공격 | 마우스 왼쪽 / J |
| 패링 (받아치기) | SPACE / 마우스 오른쪽 |
| 대시 | SHIFT |
| 메뉴 · 소리 설정 | ESC |
| 다시 하기 | R |

🟨 노란 범위 = 받아치기 · 🟥 빨간 범위 = 못 막음, 대시로 피하기

## 플레이 기록 안내

새 버전부터는 게임 개선을 위해 **익명 플레이 기록**(보스별 도전·사망 횟수, 맞은 공격 종류, 플레이 시간, 해상도)이 전송됩니다. 이름·이메일 등 개인 정보는 보내지 않습니다.
